# Tài liệu cài đặt và demo JobVista

Mở CAI_DAT_VA_DEMO_JOBVISTA.html bằng trình duyệt để đọc, hoặc file Markdown để biên tập.

- Phần 1–8: giải thích và code trích nguyên văn, có vị trí nguồn.
- Phần 9: giới thiệu, trang chủ, kịch bản demo.
- Phần 10: 16 ảnh thật; DANH_MUC_ANH.md ghi chú thích riêng.
- code/: các đoạn trích .txt để chèn báo cáo, không chạy độc lập.
- CV_demo/: CV PDF giả lập đã dùng chụp ảnh.
- manifest.json: revision nguồn, danh mục đoạn code, checksum các tệp.

Khi gửi bạn làm Word, gửi cả ZIP và giải nén trước khi mở HTML. Ảnh chương 3 nằm trong gói Hinh_Chuong_3_JobVista đã cung cấp trước đó.
